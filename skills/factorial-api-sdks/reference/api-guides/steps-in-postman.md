# Steps in Postman

1. Go to your Postman account > paste the factorial URL ([https://api.factorialhr.com/api/v1/me](https://api.factorialhr.com/api/v1/me)) > select Authorization OAuth 2

<Image align="center" width="250px" src="https://files.readme.io/cc7f3ec-image.png" />

2. Scroll to the "Configure a new token" section

<Image align="center" width="2px" src="https://files.readme.io/fff7bf8-image.png" />

<Image align="center" width="300px" src="https://files.readme.io/dcf9810-image.png" />

<Image align="center" width="8px" src="https://files.readme.io/e73f231-image.png" />

<Image align="center" width="300px" src="https://files.readme.io/c95d7e4-image.png" />

The links to make it faster 🤗

* **Auth URL**: [https://api.factorialhr.com/oauth/authorize](https://api.factorialhr.com/oauth/authorize)
* Access **Token URL**: [https://api.factorialhr.com/oauth/token](https://api.factorialhr.com/oauth/token)
* The **callback URL** has to be the same as the repository (The callback URL has to be the same in Postman as in the repository.) In case it´s not the same, go to the repository and edit the URL

<Image align="center" width="200px" src="https://files.readme.io/72ffee0-image.png" />

* **Client ID** and **Client secret** should be taken from the [repository](https://api.factorialhr.com/oauth/applications) by the ADMIN

3. Click on "Request new access token"

<Image align="center" width="250px" src="https://files.readme.io/521fdc5-image.png" />

4. Use the Token!
