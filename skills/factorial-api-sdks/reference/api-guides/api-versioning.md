# API versioning

In Factorial, move fast and improve constantly. Our product teams are always figuring out how to deliver more value to our clients, and this also involves making changes to our API.

With public API versioning, we reconcile this agility with the fact that API users need stability and time to adapt to new changes.

We are releasing a new API version at the beginning of each quarter and supporting each version for one year. This means that you will have 9 months to review the changelog and adapt/update your code to the latest API version. After the 9 months, your API request to an unsupported version will be served using the oldest version schema.
